**Scope:** Workspace, popup, sidepanel, registry, storage, messaging, permissions, tests.
**Exit gate:** Tasks của P0 hoàn tất; AC và test tương ứng pass.

**Exit gate:** Tasks của P1 hoàn tất; AC và test tương ứng pass.

## P2 — CSS & UI

**Exit gate:** Tasks của P2 hoàn tất; AC và test tương ứng pass.

## P3 — Browser Debugging
**Scope:** 8 tools: TOOL-025..032.
**Exit gate:** Tasks của P3 hoàn tất; AC và test tương ứng pass.

## P4 — API & Automation
**Scope:** 10 tools: TOOL-033..042.
**Exit gate:** Tasks của P4 hoàn tất; AC và test tương ứng pass.

## P5 — Release & Hardening
**Scope:** security audit, E2E, documentation, packaging.
**Exit gate:** Tasks của P5 hoàn tất; AC và test tương ứng pass.

**Dependencies:** P0 → P1 → P2 → P3 → P4 → P5; có thể song song tool trong cùng phase sau khi shared infrastructure ổn định. Không giả định thời lượng cố định.
