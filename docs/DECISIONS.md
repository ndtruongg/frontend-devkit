# Architecture Decision Records (initial)

- ADR-001 WXT + Vue 3 + TypeScript: one project, multi-entrypoint MV3.
- ADR-002 Local-first: no backend required; privacy default.
- ADR-003 Typed registry: stable TOOL IDs, lazy-load UI.
- ADR-004 Optional host permissions: user-initiated browser access.
- ADR-005 IndexedDB for large structured user data; chrome.storage.local for settings.
- ADR-006 Scope realism: network metadata observable, response bodies not guaranteed; mocking via supported DNR redirects or explicit alternative.

Any change requires a new ADR with tradeoffs, not silent scope expansion.
